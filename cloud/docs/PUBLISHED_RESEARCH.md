# Deployment-local synthetic research artifact

The authenticated research-progress route reads one fixed bundled report. It
checks SHA-256 on the exact bytes parsed, then applies the existing fail-closed
research validator. No caller path, remote URL, environment-selected report,
upload endpoint, database migration or market-data ingestion is added.

This is a projection of the existing Lab synthetic stress experiment, not newly
trained NAS100 intelligence: three synthetic seeds, two artificial cost cases,
six recorded runs and eight descriptive comparison rows. No authentic candles,
broker/account data, credentials, paths or model weights are bundled. Aggregate
counts are copied from the existing validated report, never invented or refitted.

The digest covers canonical LF bytes. A scoped Git attribute preserves LF in
Windows checkouts and Linux deployments. Never pin a workstation's CRLF bytes
while deploying Git's LF-normalized blob. Integrity rejection remains mandatory.

The displayed modification time preserves the original source file's observed
mtime (2026-11-06T06:38:01.389105+00:00). It is not an independently attested
generation time, current market-data timestamp or evidence of a fresh run.
Fresh authenticated HTTP response time and artifact age are separate concepts.

The v1 phone contract retains `LOCAL_UNATTESTED_SYNTHETIC_REPORT`: local means
local to the serving API deployment, not a dependency on the user's laptop.
Integrity pinning is not certification of market performance. No win-rate,
profitability, model-selection, real-training or inference permission is granted.
Missing, changed or unsafe files return an unavailable report with empty results.

The endpoint remains device-authenticated and no-store. Existing pairing and
refresh sessions remain compatible. Model status remains MODEL_NOT_READY;
execution remains RESEARCH_ONLY_LOCKED and NO_TRADE. Real NAS100 research still
requires independently verified timestamps, sessions, contract/cost evidence,
labels, chronological evaluation and reviewed training activation.
