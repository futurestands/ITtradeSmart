Run an offline, unvalidated backtest over a broker CSV export. Usage from
backend: python tools/run_nas100_research.py --csv
data/nas100/USTECH100M_M5.csv --point-size 0.1 --spread-points 20 --start 500
--stop 1000 NOTE: --point-size and --spread-points must come from actual
broker specs and a conservative observed spread scenario; example numbers are
placeholders only. Never trade using a result from this utility. This is
research, not a signal API.
